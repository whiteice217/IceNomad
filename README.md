## ✨ Features

- 🐧 Native SwiftUI interface
- 📡 TCP Client support
- 📻 Native RNode (LoRa) connectivity, with Bluetooth pairing
- ❄️ Reticulum network integration (announces, Links, real packet routing)
- 🔐 Cryptographic identity management
- 💬 LXMF messaging — sending and receiving over a real Link, working reliably
- 🌎 NomadNet browser — fetches and renders real pages *(rough around the edges — see status below)*
- 📷 QR code sharing for your address
- 🌗 Adaptive light/dark theme
- 🚀 Live connection monitoring
- ⚡ Mobile-first design

## 🐧 About IceNomad

IceNomad is a native iOS client for the Reticulum Network Stack, designed to bring decentralized communications to mobile devices.

Whether connecting through TCP to a remote transport node or directly over LoRa using an RNode, IceNomad aims to make encrypted mesh networking simple, intuitive, and accessible from your pocket.

The long-term goal is to provide a complete mobile experience for the Reticulum ecosystem, including:

- Reticulum networking
- LXMF messaging
- NomadNet browsing
- Identity management
- Remote node connectivity
- LoRa mesh communications
